# Character asset direction

## Runtime asset

`src/assets/images/mindy-maximus-v2.png` is the transparent prototype cutout used across the campus, settings and AMAtraining screens.

## Identity references

- Maximus: official 3D boy artwork supplied by the user (`Maximus_klass.png`, `Максимус_1.png`).
- Mindy: textbook panda artwork supplied by the user (`img36.jpg`, `img54.jpg`).

The high-resolution source references remain outside this repository. The runtime cutout is a generated prototype, not a replacement for the official character masters.

## Generation method

The asset was created with the built-in image-generation tool in identity-preserving edit mode, using a transparent background.

Final prompt summary:

> Create Maximus and Mindy together in one polished contemporary 3D animated universe. Maximus must remain the recognizable human boy from the references: large brown eyes, dark hair, blue-and-yellow academic clothing and friendly teacher/mentor role. Mindy must remain the recognizable textbook panda: round panda face, black eye markings, white hair tuft, magenta bow and magenta dress. Full-body duo, soft studio light, transparent background, no campus, no text, no extra characters, no capes, no major facial redesign.

Do not use the previous two-panda concept. Maximus is never represented as a panda.

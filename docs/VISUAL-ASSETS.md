# Visual assets

## Campus map

`src/assets/images/smartland-campus-v2.png` is the current runtime campus background. It preserves the five-building composition from the original prototype while consolidating the architecture into blue, violet, magenta, white and restrained yellow. Landscaping and sky remain intentionally softer than the buildings.

The map was produced with the built-in image-generation tool in a composition-preserving edit. No text, signs, characters or UI controls are baked into the bitmap; venue flags and trainer buttons remain accessible HTML layers.

## Brand mark

The Smartland header mark is an inline SVG inspired by the AMAKids magenta diamond and the embroidered patch on Mindy's uniform. It is code-native so it remains sharp, themeable and accessible at every screen density.

## Screen backgrounds

All prototype screens use the same soft lavender surface family. Dark blue-violet panels are reserved for character-led instruction and AMAtraining question/fact moments.

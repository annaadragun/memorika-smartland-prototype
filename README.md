# Smartland Academy — Memorika prototype

Кликабельный адаптивный концепт оболочки курса Memorika.

## Сценарии

- кампус с четырьмя направлениями тренировки;
- свободная тренировка: настройки → показ → ответ → результат;
- нейротренировка: маршрут → миссия → упражнение → карточка-открытие;
- переключение русского и английского языка;
- адаптация для desktop, tablet и mobile.

## Локальный просмотр

Из корня проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте `http://127.0.0.1:4173`.

Изображения кампуса и персонажей — концептуальные AI-ассеты для прототипа, не production-графика.
